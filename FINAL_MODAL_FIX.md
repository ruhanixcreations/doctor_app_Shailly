## Design Rationale

### Why Large Modal Buttons?
1. **Primary Actions:** Download and Close are the main actions
2. **Visibility:** Stand out against gradient background
3. **Accessibility:** Easier to click for all users
4. **Professional:** Matches the importance of the modal

### Why Small Table Buttons?
1. **Space Efficiency:** Many rows in table
2. **Secondary Actions:** Open modal is a secondary action
3. **Clean Layout:** Doesn't overwhelm the table
4. **Consistency:** Matches other table action buttons
